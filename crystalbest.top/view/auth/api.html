请求签名

每个 OpenAPI 请求都使用 HMAC-SHA256。Secret 不直接发送到服务器请求头中。

HeaderX-CB-API-KEY创建时生成的完整 API Key
HeaderX-CB-API-TIMESTAMPUnix 秒或 13 位毫秒时间戳，允许 ±{$apiDashboard.signature_window_seconds} 秒
HeaderX-CB-API-NONCE16–64 位随机字符串，每次请求必须不同
HeaderX-CB-API-SIGNATURE64 位十六进制 HMAC-SHA256 签名
Canonical String timestamp\nnonce\nMETHOD\n/path\nnormalized_query\nsha256(body)

Query 按参数名排序并使用 RFC3986 编码。当前接口全部是 GET，因此 body 为空字符串。

signature = HMAC_SHA256_HEX(api_secret, canonical_string)

只读 API V1

以下接口只读取已提交到数据库的账户/交易配置数据，不读取 Ticker、K 线、盘口、BBO、指数价、标记价或实时资金费率。

GET/openapi/v1/account/profile

用户资料：UID、掩码邮箱/手机、昵称、KYC、风险等级、语言、时区等。

GET/openapi/v1/account/perpetual-positions

当前非零合约持仓；返回方向、数量、开仓价、盈亏平衡价、已实现盈亏、杠杆等，不返回标记价和未实现盈亏。

GET/openapi/v1/account/balances

用户持币：现货与永续全仓账户的可用、冻结和总余额。

GET/openapi/v1/account/deposits?page=1&page_size=20

充值记录；默认 20 条，最多每页 100 条。

GET/openapi/v1/account/withdrawals?page=1&page_size=20

提币记录；包括地址、数量、费用、状态、Tx Hash 与处理时间。

GET/openapi/v1/markets/supported

平台支持资产、现货交易对、永续合约及静态交易参数；market_data_included=false。
